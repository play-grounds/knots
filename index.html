knots

Validators for the Bitcoin Knots BLAKE2b chains (testnet4 and mainnet), built on the bitcoin-desktop schema engine with its Knots overlay.

  • headers — the latest twelve headers of each chain over Nostr (NIP-333), verified in your tab
  • fork boundary — the blocks where each chain left Bitcoin Core (last shared block, Knots-only SHA256d blocks, first BLAKE2b block), verified in your tab
  • tip block — the newest block of each chain: header rules, block structure, and the contextual rules that need no UTXO set, verified in your tab (stage 1: static snapshot)
