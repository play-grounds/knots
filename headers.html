how this works

Transport: NIP-333, Bitcoin block headers over Nostr — one replaceable kind-33333 event per network carrying the latest twelve headers (specification; the btcb2 / tbtc4b2 codes and the 164-byte header are proposed here).

Engine: bitcoin-desktop/schema@cc61f3e95d64 via jsDelivr, unmodified; the BLAKE2b support is the knots-blake2b overlay (a 164-byte header variant, the BLAKE2b proof-of-work hash, and seven fork rules), loaded with createKernel. Events are checked with the engine's NIP-01 verifier before their content is read. Relays: nos.lol, damus, nostr.band. Block hashes link to mempool.guide, which follows the BLAKE2b chains. Source: play-grounds/knots.
